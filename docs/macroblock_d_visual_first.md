# DOBO Macroblock D — Visual-first capability expansion

This macroblock changes the acceptance priority of Motor DOBO.

A feature is not accepted because it compiles or because a mesh is printable. It must create a visible, generalizable change in the frozen visual benchmark while preserving manufacturing constraints.

D1 introduces true lobed and continuously twisted implicit fields plus four reusable body morphologies: undulating shell, spiral ribbed, origami crown, and sculptural cluster.

The eight-case benchmark always emits real STL/3MF-derived visual evidence. Human visual acceptance remains mandatory.
